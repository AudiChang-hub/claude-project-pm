## The list's rules (re-read 2026-10-19)

From its `CONTRIBUTING.md` and `.github/ISSUE_TEMPLATE/recommend-resource.yml`:

- **Web issue form only.** No pull requests, and an issue opened with the `gh` CLI is not accepted.
  Skipping the form can get the account temporarily restricted on that repository.
- **The recommendation must be made by a person.** The resource itself may be partly or entirely
  written by a coding agent, so being built with Claude Code is fine to say; the form, though, has to
  be filled in by a human. Treat the answers below as notes and write the description in your own
  words.
- **Eligibility:** at least 14 days since the first commit on the default branch with active
  development since, or at least 100 stars. This repository's first commit is 2026-10-17, so the
  earliest date is 2026-10-31. Ineligible submissions are closed automatically.
- One resource per submission; Claude Code specific; not already on the list. A bot validates the
  submission and comments; a maintainer decides, and no answer is guaranteed.
- Description: 1–3 sentences, 10–500 characters, one line, describes what it does (not a sales
  pitch), does not address the reader, no emojis.
- A bot checks the license; this repository has an MIT `LICENSE`.
- The list notes that getting listed should not be part of a promotion strategy, and that its
  Discussions are not for promoting projects.
