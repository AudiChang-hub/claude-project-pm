## How the list takes submissions (read 2026-10-19)

From its `CONTRIBUTING.md` and `.github/ISSUE_TEMPLATE/recommend-resource.yml`:

- **Not a pull request.** Submit through the web issue form "Recommend a Resource". Pull requests,
  and issues opened with the `gh` CLI, are not accepted; the form must be filled in by a person.
  Skipping the form can get the account temporarily restricted on that repository.
- **Eligibility:** at least 14 days since the first commit on the default branch with signs of
  active development, or at least 100 stars. Ineligible submissions are closed automatically.
  This repository's first commit is 2026-10-17, so **submit on or after 2026-10-31**.
- One resource per submission; Claude Code specific; not already listed.
- Description: 1–3 sentences, 10–500 characters, says what it does, not a sales pitch, does not
  address the reader, no emojis.
- A bot checks the license (this repository has an MIT `LICENSE`).
